    1 Arquivo texto com acumuladores

    2023-2 Q1 e Q2 · 2025-2 Q1 · 2022-1 Q2

    Enunciado típico: "mostre o arquivo, calcule a média e conte quantos estão acima dela. Mantenha só uma linha em memória". A média só existe depois de ler tudo, então são duas passagens pelo arquivo: uma para somar e outra para contar.

    def mostra(nomeArq):
    print("Conteúdo em", nomeArq + ":")
    arquivo = open(nomeArq, "r")
    for linha in arquivo:
        print("\t", linha, end="")
    print()
    arquivo.close()
    return None

def somaEQuantidade(nomeArq):
    soma = 0
    qtd = 0
    arquivo = open(nomeArq, "r")
    for linha in arquivo:
        for texto in linha.split():
            soma += float(texto)
            qtd += 1
    arquivo.close()
    return soma, qtd

def contaAcima(nomeArq, media):
    acima = 0
    arquivo = open(nomeArq, "r")
    for linha in arquivo:
        for texto in linha.split():
            if float(texto) > media:
                acima += 1
    arquivo.close()
    return acima

# Principal
nomeArquivo = input()
mostra(nomeArquivo)
soma, qtd = somaEQuantidade(nomeArquivo)
media = soma / qtd
print("Média dos Números em", nomeArquivo + ":", media)
print("Quantidade Acima de", media, "em", nomeArquivo + ":", contaAcima(nomeArquivo, media))

    Variação "maior até agora" (2023-2 Q2): guarde maior = None e linhas = []. Para cada palavra, se maior is None ou len(p) > len(maior), troque a palavra e reinicie linhas = [numeroDaLinha]. Se for igual à atual e a linha ainda não estiver na lista, acrescente. Numere as linhas com um contador que começa em 0 e soma 1 a cada linha lida.

    Armadilhas

    • Ler o arquivo inteiro com read() ou readlines() viola a restrição do enunciado.
    • print(linha) duplica a quebra de linha. Use end="".
    • Esquecer arquivo.close() ou o return do subprograma. O gabarito fecha sempre.
    • Imprimir a média arredondada quando o exemplo mostra o float cru (8.131233333333334).

    2 Dicionário: contagem, moda e ordenação

    2024-1 Q2 · 2025-1 Q2 · 2025-2 Q2 · 2022-2 Q2

    Enunciado típico: "conte as ocorrências, mostre a moda (todas, se houver empate) e escreva em ordem alfabética". O padrão é sempre o mesmo: construir o dicionário, achar o maior valor, listar as chaves que têm esse valor.

    def contaPalavras(nomeArq, minimo, maximo):
    contagem = dict()
    arquivo = open(nomeArq, "r", encoding="utf-8")
    for linha in arquivo:
        for palavra in linha.replace(",", "").upper().split():
            if minimo <= len(palavra) <= maximo:
                if palavra in contagem:
                    contagem[palavra] += 1
                else:
                    contagem[palavra] = 1
    arquivo.close()
    return contagem

def moda(contagem):
    maior = 0
    for vezes in contagem.values():
        if vezes > maior:
            maior = vezes
    return [chave for chave in contagem.keys() if contagem[chave] == maior]

def mostraOrdenado(contagem):
    for palavra in sorted(contagem.keys()):
        vezes = contagem[palavra]
        print(palavra, "ocorreu", vezes, "vez" if vezes == 1 else "vezes")

# Principal
nomeArquivo = input()
minimo, maximo = map(int, input().split())
mostraOrdenado(contaPalavras(nomeArquivo, minimo, maximo))

    Primeiro e último nome (2024-1 Q2): partes = linha.split(), primeiro nome em partes[0], sobrenome em partes[-1]. Dois dicionários, uma passagem. Se os dois estiverem vazios, imprima Arquivo Vazio! e não chame a moda.

    Dicionário como tabela de tradução (2022-1 e 2023-1): siglas = {"real": "BRL", "euro": "EUR", "dolar": "USD"} e depois siglas[moeda].

    Armadilhas

    • contagem[palavra] += 1 sem testar in gera KeyError.
    • Uma linha em branco faz partes[0] estourar. Teste if partes: antes.
    • .values() e .keys() levam parênteses. .value() foi um dos erros plantados em 2025-1.
    • Plural: "1 vez", "2 vezes". O enunciado de 2025-2 cobra isso na saída.
    • Moda com empate retorna uma lista, não um único valor.

    3 Arquivo binário com struct

    2022-1 Q1 · 2023-1 Q1 · 2024-1 Q3

    Enunciado típico: "o arquivo binário tem registros de 2 strings de 20 bytes e 1 float". Duas metades: gerar o .bin a partir do .txt (valia 2,0 a 2,5 pontos) e consultar o .bin.

    import struct
registro = struct.Struct("20s 20s f")    # 20 bytes + 20 bytes + float

def geraBinario(nomeTxt, nomeBin):
    txt = open(nomeTxt, "r")
    binario = open(nomeBin, "wb")
    for linha in txt:
        moeda1, moeda2, taxa = linha.strip().split("#")
        bloco = registro.pack(moeda1.encode("utf-8"), moeda2.encode("utf-8"), float(taxa))
        binario.write(bloco)
    txt.close()
    binario.close()
    return None

def converte(nomeBin, origem, destino, valor):
    arquivo = open(nomeBin, "rb")
    while True:
        bloco = arquivo.read(registro.size)
        if not bloco:                       # fim do arquivo
            break
        m1, m2, taxa = registro.unpack(bloco)
        m1 = m1.decode("utf-8").rstrip(chr(0))   # tira o preenchimento \x00
        m2 = m2.decode("utf-8").rstrip(chr(0))
        if (m1, m2) == (origem, destino):
            arquivo.close()
            return valor * taxa
        if (m1, m2) == (destino, origem):   # registro no sentido contrário
            arquivo.close()
            return valor / taxa
    arquivo.close()
    return None                             # moeda não consta

# Principal
siglas = {"real": "BRL", "euro": "EUR", "dolar": "USD"}
try:
    nomeBin = input()
    origem = input()
    destino = input()
    valor = float(input())
    total = converte(nomeBin, origem, destino, valor)
    if total is None:
        print("Alguma moeda não consta")
    else:
        print("Você pagará %.2f %s por %s %s" % (total, siglas[destino], valor, siglas[origem]))
except FileNotFoundError:
    print("Um dos arquivos não foi encontrado ou você digitou errado")
except ValueError:
    print("Você colocou um valor não correspondente")

    Variação 2024-1 Q3: struct.Struct("8s 5s f") guarda CEP, loja e frete. Para consultar, normalize o CEP digitado com input().replace(".", "").replace("-", ""), monte um dicionário {loja: frete} só com os registros daquele CEP e depois percorra produto.txt somando preço e frete. A primeira linha de produto.txt é o nome do produto. Dicionário vazio significa "O produto desejado não pode ser entregue neste frete".

    Armadilhas

    • Strings no struct são bytes: encode ao gravar, decode ao ler.
    • Um campo 20s é completado com \x00. Sem rstrip(chr(0)) a comparação de strings nunca é verdadeira.
    • Modos de abertura: "wb" e "rb". Em modo texto o programa quebra.
    • O campo f é float de 32 bits (5.17 volta como 5.170000076...). Formate com %.2f ou round(x, 2).
    • Valor de entrada que não é número: float() levanta ValueError. A mensagem do enunciado tem que sair palavra por palavra.
    • O enunciado de 2023-2 em diante diz "não serão aceitas respostas que usem bibliotecas", mas o gabarito de 2024-1 usa import struct. Pergunte ao tutor se a prova atual permite.

    4 Matriz lida de arquivo e pontos no plano

    2024-1 Q1 · 2025-1 Q1 · 2023-1 Q2 e Q3

    Aqui o arquivo vira uma lista de listas, que cabe na memória por ser a estrutura pedida. O trabalho é percorrer índices sem sair dos limites.

    def carrega(nomeArq):
    matriz = []
    arquivo = open(nomeArq, "r")
    for linha in arquivo:
        matriz.append(list(map(int, linha.split())))
    arquivo.close()
    return matriz

def vizinhos(matriz, lin, col):
    valores = []
    for l in range(lin - 1, lin + 2):
        for c in range(col - 1, col + 2):
            if 0 <= l < len(matriz) and 0 <= c < len(matriz[l]) and (l, c) != (lin, col):
                valores.append(matriz[l][c])
    return valores

def todosMaiores(matriz, lin, col):
    for v in vizinhos(matriz, lin, col):
        if v <= matriz[lin][col]:
            return False
    return True

# Principal
matriz = carrega(input())
for lin in range(len(matriz)):
    for col in range(len(matriz[lin])):
        if todosMaiores(matriz, lin, col):
            print("Linha %d, Coluna %d, Valor = %d" % (lin + 1, col + 1, matriz[lin][col]))

    Pontos mais distantes (2023-1 Q2): leia com input() até uma linha vazia, guarde tuplas e compare todos os pares. Sem math: a raiz é ** 0.5.

    def lePontos():
    pontos = []
    linha = input()
    while linha != "":
        x, y = map(int, linha.split())
        pontos.append((x, y))
        linha = input()
    return pontos

def distancia(a, b):
    return ((b[0] - a[0]) ** 2 + (b[1] - a[1]) ** 2) ** 0.5

def maisDistantes(pontos):
    melhor = None                       # (distância, ponto A, ponto B)
    for i in range(len(pontos)):
        for j in range(i, len(pontos)): # j começa em i: um único ponto dá 0.00
            d = distancia(pontos[i], pontos[j])
            if melhor is None or d > melhor[0]:
                melhor = (d, pontos[i], pontos[j])
    return melhor                       # None se a lista está vazia

    Na Q3 de 2023-1 a única mudança é a origem: lePontos passa a ler de um arquivo com for linha in arquivo e o resto é reaproveitado.

    Armadilhas

    • Índice negativo em Python não dá erro: matriz[-1] é a última linha. Por isso o teste 0 <= l é obrigatório.
    • A célula não é vizinha dela mesma. Exclua (l, c) == (lin, col).
    • "Todos maiores" é estrito: um vizinho igual elimina a célula.
    • Saída em base 1 (lin + 1), enquanto o código usa base 0.
    • Lista vazia: o enunciado pede a mensagem "Não existem pontos mais distantes!".

    5 Reescrever um arquivo texto com arquivo auxiliar

    2022-1 Q3 · 2022-2 Q3

    Enunciado típico: "remova as linhas que contêm primo" ou "atualize o estoque". Como o arquivo não cabe na memória, escreve-se um auxiliar e depois copia-se de volta. O gabarito de 2022-2 usa exatamente esse caminho.

    def ehPrimo(n):
    if n <= 1:
        return False
    for divisor in range(2, int(n ** 0.5) + 1):
        if n % divisor == 0:
            return False
    return True

def temPrimo(linha):
    for texto in linha.split():
        if ehPrimo(int(texto)):
            return True
    return False

def removeLinhasComPrimo(nomeArq):
    original = open(nomeArq, "r")
    auxiliar = open(nomeArq + "aux", "w")
    for linha in original:
        if not temPrimo(linha):
            auxiliar.write(linha)
    original.close()
    auxiliar.close()
    # copia de volta
    auxiliar = open(nomeArq + "aux", "r")
    original = open(nomeArq, "w")
    for linha in auxiliar:
        original.write(linha)
    auxiliar.close()
    original.close()
    return None

# Principal: mostra(nome, "antes"), removeLinhasComPrimo(nome), mostra(nome, "depois")

    Registro com # (2022-2 Q3): cod, desc, qtd, preco = linha.split("#"). O último campo traz o \n, então grave de volta com "#".join(...) ou concatenando sem remover a quebra.

    Armadilhas

    • Abrir o original em "w" antes de ler apaga tudo. Primeiro leia do original e grave no auxiliar.
    • Linha vazia: split() devolve lista vazia, temPrimo dá False e a linha é mantida. Está correto, mas confirme com o exemplo.
    • Negativos, 0 e 1 não são primos.
    • Mostrar o conteúdo antes e depois faz parte da pontuação.

    Ler e corrigir código

    A AP2 de 2025-1 trocou "escreva um programa" por "explique este código" e "ache 5 erros". Treine as duas habilidades.

    2025-1 Q1: o que cada subprograma faz

    Estrutura de resposta: o que faz, o que recebe e devolve, por que é necessário.

    • carrega(nm): abre o arquivo, converte cada linha em uma lista de inteiros (split e map(int, ...)) e devolve a lista de listas. Isola a leitura do resto do programa.
    • passaNaRestricao(lin, col, listaDeListas): examina os 8 vizinhos da célula (lin ± 1, col ± 1), ignorando posições fora da matriz e a própria célula. Devolve False assim que acha um vizinho menor ou igual ao valor da célula, e True se todos os vizinhos existentes são maiores.
    • adj(listaDeListas): percorre todas as células, chama passaNaRestricao e imprime linha, coluna (base 1) e valor das que passam.
    • Principal: lê o nome do arquivo, chama carrega para obter a matriz e entrega a matriz a adj, que produz a saída. O programa responde "quais células são menores que todos os seus vizinhos".

    Para ganhar ponto extra: len(listaDeListas[0]) assume que todas as linhas têm o mesmo tamanho.

    2025-1 Q2: os erros plantados

    Código da moda de nomes (2024-1 Q2). Identificáveis no texto do PDF:

    • partesNome[len(partesNome)] estoura com IndexError. Correção: partesNome[-1] ou [len(partesNome) - 1].
    • dicionario.value() não existe. Correção: dicionario.values().
    • else no programa principal sem os dois-pontos. Correção: else:.

    O texto extraído do PDF perde a indentação, então os outros dois erros não foram confirmados. Abra a prova original e confira a indentação do return None, do print de "Arquivo Vazio!" e do bloco do else.

    Lista de caça-erros

    • Sintaxe: dois-pontos, parênteses, aspas, indentação.
    • Nomes de métodos: values, keys, append, strip, split.
    • Índices: len(x) usado como índice, range que para um antes.
    • Operadores: = no lugar de ==, < no lugar de <=.
    • Tipos: faltou int() ou float() sobre texto lido.
    • Fluxo: return dentro do laço, close() esquecido, variável usada sem inicializar.
